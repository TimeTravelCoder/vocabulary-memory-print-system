# 📖 A4 单词记忆本·字帖打印系统

专为英语学习者打造的 **A4 纸张排版与单词默写记忆系统**。系统直接联动 `中英合并释义_JSON` 中的 957 本各类考级词书，支持自定义范围与模板，一键调起浏览器高清物理打印或导出为 PDF。

---

## 🚀 快速启动

1. **双击启动**：
   - 直接双击当前文件夹下的 **`启动系统.bat`**。
   - 系统将自动打开系统默认浏览器，访问 `http://localhost:8899/index.html`。

2. **命令行启动（备选）**：
   ```bash
   python server.py
   ```

---

## 🌟 核心特色与功能

### 1. 四大记忆本模板自由切换
- **模板一：标准抄写精读本**（默认推荐）  
  上方完整呈现“单词 + 音标 + 中文释义 + 英文释义”，下方为规范抄写区：
  - 单词抄写 5 遍（带规整对齐槽位与序号提示）
  - 音标抄写 3 遍（专属音标书写位）
  - 英文释义抄写 2 遍（最多精选 2 条核心原义，双线规范抄写）
- **模板二：艾宾浩斯复习打卡本**  
  卡片右上角集成 **1d / 2d / 4d / 7d / 15d** 遗忘曲线打卡气泡与掌握度评分星级。
- **模板三：英语书法四线三格帖**  
  单词抄写区自动渲染标准的**四线三格**英语书法练习基准线，纠正书写习惯。
- **模板四：双语默写自测本**  
  支持一键遮挡隐藏“中文释义”、“英文释义”或“英文单词”，打印出来即为一份自测默写答卷。

### 2. 灵活的学习计划切分
- **按天切分（推荐）**：可自定每天背诵词数（12词 / 16词 / 20词 / 24词 / 32词），自动生成 Day 1、Day 2、Day 3... 方便每日针对性打印。
- **序号区间自由选**：例如打印第 1 ~ 40 个词。
- **全本打印**：支持整本词书连续分页排版。

### 3. 严格精准的 A4 打印排版（物理级零跑版）
- 严格遵循 A4 纸张规范（210mm × 297mm），采用 CSS Paged Media 分页隔离机制，**任何一个单词的卡片都不会被强行跨页劈开**。
- 支持自由调整**每页词数**：
  - `4 词/页`：黄金比例，书写舒适，空间充裕。
  - `3 词/页`：大字体版，适合长释义或初学者。
  - `5 词/页`：紧凑版，节省纸张，适合考前冲刺。
- 可选附带**专属 A4 封面页**（印有书名、学习者姓名、开始与目标日期）。

## 🖨️ 打印与保存 PDF 技巧

1. 在左侧面板配置好词书和范围后，点击左下角的 **【🖨️ 立即打印 / 另存为 PDF】** 按钮（或直接按键盘快捷键 `Ctrl + P`）。
2. 在浏览器弹出的打印窗口中：
   - **目标打印机**：选择您的实体打印机，或选择 **“另存为 PDF”**。
   - **纸张尺寸**：确认选择为 **A4**。
   - **页边距**：选择 **“无”** 或 **“默认”**。
   - **更多设置**：勾选 **“背景图形”**（确保浅灰色书写辅助线和四线三格能被清晰打印出来）。
